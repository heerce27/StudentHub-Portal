Css Notes:
1. CSS Variables (:root)
- Stores reusable values like colors, radius and shadows.
- var(--primary) is used to reuse a variable.
- Makes the theme easier to change.

2. Universal Selector (*)
* { margin:0; padding:0; box-sizing:border-box; }
- Resets default browser spacing.
- border-box includes content, padding and border in width/height.

3. Body & Background
- Uses linear-gradient and radial-gradient for the modern background.
- overflow-x:hidden prevents horizontal scrolling.
- position:relative is used for positioning/background effects.
4. Flexbox
- display:flex creates a flexible layout.
- justify-content controls the main-axis alignment.
- align-items controls the cross-axis alignment.
- Used mainly for header/menu/button alignment.

5. CSS Grid
- display:grid creates a grid layout.
- repeat(3, 1fr) creates 3 equal columns.
- fr means fraction of available space.
- Used for dashboard/cards.
- Grid is mainly two-dimensional; Flexbox is mainly one-dimensional.

6. Responsive Design
- Uses @media(max-width:900px) and @media(max-width:600px).
- Dashboard changes from 3 columns to 2 and then 1.
- Makes the website work on desktop, tablet and mobile.

7. Buttons
- .btn, .btn-primary and .btn-secondary are reusable classes.
- :hover changes styling when the mouse is over an element.
- transform:translateY(-3px) moves an element upward.

8. Glassmorphism
- Uses rgba() transparent backgrounds and backdrop-filter:blur().
- Creates a glass-like UI.
- Used in header, cards and forms.
- RGBA = Red, Green, Blue, Alpha (transparency).

9. Cards
- Use background, border-radius, padding and box-shadow.
- :hover with transform creates a floating effect.
- border-radius makes corners rounded.
- box-shadow gives depth/elevation.

10. Forms
- Inputs/select/textarea use width:100%.
- :focus styles an input when it is selected.
- Difference: :hover = mouse over; :focus = element is selected/active.

11. Sidebar
- position:fixed keeps it attached to the viewport.
- height:100vh means full viewport height.
- transform:translateX(-100%) hides it outside the screen.
- .sidebar.active uses translateX(0) to show it.
- z-index controls stacking order.

12. Overlay
- Covers the page when the sidebar is open.
- Uses position:fixed, full width/height and transparency.
- Helps focus attention on the sidebar and close it by clicking outside.

13. Animations
- @keyframes defines animation stages.
- spin is used for the loading spinner.
- fade is used for fade-in effects.
- infinite means the animation repeats continuously.

14. Transition vs Animation
- transition = smooth change between states, e.g. hover.
- animation = can run automatically using @keyframes.

15. object-fit:cover
- Makes an image fill its container while keeping its aspect ratio.
- Excess parts may be cropped.
- Used for event/gallery/profile images.

16. z-index
- Controls stacking order of overlapping elements.
- Higher z-index generally appears above lower z-index.
- Sidebar is above the overlay.
